Singular Value Decomposition & A Coda for Principal Component Analysis

Created on May 13, 2026

2026   ·   fundamentals

The connecting component between Singular Value Decomposition (SVD) and Principal Component Analysis (PCA) is the eigendecomposition. Principal component analysis requires keeping the top-k eigenvectors for reconstruction of the maximal information components. We can study the effect of this with a Gaussian.

Following on from the previous post, we used a covariance matrix to define conditionally dependent multivariate Gaussians. The covariance matrix can be thought of as a set of operations, a rotation, followed by scaling, finishing off with a final rotation. This looks like,

\[X = U \Sigma V^T,\]

for a given matrix X, the rotation components \(U\) and \(V\), with scaling \(\Sigma\). To relate to eigendecomposition, we consider a symmetric Positive SemiDefinite (PSD) matrix M,

\[M = X^T X,\]

where X is not necessarily square, but M is. Substituting in the SVD for X and eliminating variables results in,

\[X^T X = V \Sigma^2 V^T,\] \[X X^T = U \Sigma^2 U^T.\]

These equations are eigendecompositions themselves for the left and right eigenvectors, so the singular values of X are,

\[\sigma_i = \sqrt{\lambda_i(X^T X)},\]

or the square roots of the non-zero eigenvalues of \(X^T X\) (equivalently \(XX^T\)). Therefore, the columns of \(U\) are eigenvectors of \(XX^T\) and the columns of \(V\) are eigenvectors of \(X^T X\).

The link between SVD and eigendecomposition allows PCA to perform a low-rank execution of decomposition for simpler operations. By taking the high dimensional dataset that PCA receives, and reducing to the axes with maximal variance, we retain the most information. With Gaussian covariance descriptions, the eigenvectors corresponded to ellipsoidal directions. Meaning that we collapse the meaningful information because it is easy to reproduce and it corresponds to a majority of the overall feature.

Low-Rank and Truncated SVD

To avoid hand-waving completely, I’ll revisit the low-rank concept for SVD. To begin, the reduced SVD assumes that for any SVD there are columns in U whose corresponding singular values are zero, so they contribute nothing to the reconstruction. Specifically for \(A \in \mathbb{R}^{m\times n}\) and \(m \ge n\),

\[U \in \mathbb{R}^{m \times m}, \Sigma \in \mathbb{R}^{m \times n}, V \in \mathbb{R}^{n \times n},\]

we can define the reduced SVD as,

\[\tilde{U} \in \mathbb{R}^{m \times n}, \tilde{\Sigma} \in \mathbb{R}^{n \times n}, \tilde{V} \in \mathbb{R}^{n \times n}.\]

This reduces the number of operations total that we need to perform. The rank of the matrix is then defined as the number of non-zero diagonal elements in \(\Sigma\). This brings another question in mind. Because there are certain columns of the matrices that we don’t need, can we take only the top-k elements from the decomposition for reconstruction?

To the machine learner, this is obviously PCA, and it directly follows that taking the top-k is an information preserving operation. But why is this? The matrix we consider is the eigendecomposition for simplicity, the diagonal elements are the eigenvalues and we get their retrieved eigenvectors from the other matrices. By considering a low-rank representation of the decomposition, we are taking only the first few eigenvalues, which means that the eigenvectors along other dimensions are zero-ed out. We order the eigenvalues based on maximal variance so that they describe the largest change. This top-k component procedure we perform to retain the eigenvectors which describe the principal information, by ordering based on variance. Therefore, PCA takes the decomposition to reduce the amount of information in a feature dataset, by describing maximal variance in the eigendecomposition.

Conclusion

We found out here exactly why PCA is related to eigendecomposition by the connection of eigendecomposition to SVD. PCA uses the low-rank description of a decomposition to retain maximally varying information in the eigenbasis. That’s the sum of everything we did here, just in a shorter form!
